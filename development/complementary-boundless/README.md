# Complementary Boundless

Complementary Boundless is the selected Complementary Reimagined r5.9.3 + Euphoria Patches 1.10.5 configuration in `shaderpacks/ComplementaryReimagined_r5.9.3 + EuphoriaPatches_1.10.5.txt`.

The profile keeps the upstream shader pack and its visual effects, while reducing shadow distance, lightshaft quality and colored-lighting volume for the RX 480. The upstream shader archive and its shader source files remain untouched.
